# Primeiro Projeto – Cálculo de gasto de energia elétrica

Este projeto em Python foi criado para praticar o ciclo *Entrada → Processamento → Saída*.

O programa solicita o **nome do aparelho**, a **potência do aparelho em watts** e o **tempo médio de uso diário em horas**. Após isso, calcula o gasto mensal de energia e seu custo estimado.
